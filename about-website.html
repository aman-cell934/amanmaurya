About Our Website

Welcome to our food ordering website demo. Explore food items, view prices and try the sample checkout experience.

About This Project

This website is a student project created to demonstrate the basic design and functionality of a food ordering website.

Users can browse food items, search the menu, select an item, view its price and continue to a sample checkout page.

This is an independent educational project and is not the official Zomato website. No real payment is processed through this demo.

Website Features

🍔 Food Menu

Browse different food items and their displayed prices.

🔎 Food Search

Find food items using the menu search feature.

💳 Sample Checkout

Select a UPI app option on the demo checkout page.

📱 Responsive Design

The layout adapts to mobile phones and computer screens.

Technology Used

HTML5: Website structure and content.

CSS3: Colors, layout, styling and responsive design.

JavaScript: Food search, order details and page navigation.
